## 🧾 About This Project

This repository is the outcome of my **first real internship** — a 15-day Summer 2024 programme at **Livewire India, Tenkasi**, completed as a first-year BCA student. The project assigned to me was a practical exercise in the full frontend development workflow — from design research to shipping code.

**What I actually built:**
- Analysed `livewireindia.com` for UI/UX problems and documented findings
- Sketched and recreated **low-fidelity wireframes** in Figma
- Built a **high-fidelity Figma prototype** with colour palette and component specs
- Coded a fully **responsive HTML/CSS/JS prototype** of the redesigned homepage

I'm sharing this publicly because it honestly shows where I was as a developer in July 2024 — a first-year student who barely knew Flexbox and had never used Git. Maybe it helps someone else just starting out.

## 🎯 Project Objectives

1. **Understand** UI/UX design thinking and the Research → Wireframe → Prototype cycle
2. **Analyse** the existing `livewireindia.com` and document its usability weaknesses
3. **Wireframe** low-fidelity and high-fidelity layouts using Figma
4. **Build** a fully responsive static frontend using HTML5, CSS3, and vanilla JS
5. **Implement** mobile-first design using CSS Flexbox, Grid, and media queries
6. **Improve** visual hierarchy, CTA clarity, and navigation UX over the original

## ✨ Features Implemented

### 🔧 UI/UX & Design
- [x] Heuristic evaluation of the original website — 7 issues documented
- [x] Low-fidelity wireframes for homepage (desktop + mobile)
- [x] High-fidelity Figma prototype with colour palette, typography, and interaction states
- [x] CSS design token system (`--primary`, `--accent`, `--text-dark`, `--shadow-md`…)
- [x] 5-variant button system (primary, outline, accent, white, outline-white)

### 💻 Frontend Development
- [x] Fully responsive landing page (`index.html`) — no frameworks, pure HTML/CSS/JS
- [x] Sticky glassmorphism navbar with scroll-triggered shadow
- [x] Animated hamburger menu (3-bar → × on click) with accessible `aria-expanded`
- [x] Mobile-first CSS: Flexbox for 1D, Grid (`auto-fill` + `minmax`) for 2D layouts
- [x] Hero section: gradient background, animated badge, and hero stat counters
- [x] Course cards with JS category filter (All / Web Dev / Embedded / Java / Network)
- [x] Scroll-reveal animations for all cards and feature items
- [x] Certification programs section with featured card variant
- [x] Contact section with client-side form validation feedback
- [x] Back-to-top button (visible after 400px scroll)
- [x] Active nav link highlighting updates as you scroll
- [x] Smooth scroll on all in-page anchor links

### 📐 Design Improvements vs the Original Site

| Original livewireindia.com | This Redesign |
|---|---|
| Double-row navbar (utility links + nav) | Single clean navbar; utility info moved to footer |
| No mobile hamburger menu | Animated hamburger with full dropdown mobile menu |
| Hero carousel with competing CTAs and dense text | Single hero — one headline, one subtitle, two CTAs max |
| Course cards: name + modes only | Cards with duration, level badge, mode tags, placement indicator |
| Generic unstyled buttons | 5-variant button system with hover states and icons |
| No scroll interactions or animations | Scroll reveal, stat counter animation, active nav tracking |
| Poor mobile layout | Fully mobile-first, tested at 375px / 680px / 900px+ |

## 📅 Learning Outcomes

### 🎨 Design Skills Gained
- **UX Design Process** — Research → Wireframe → Prototype → Test (not just making it look nice)
- **Low-fidelity wireframing** in Figma to iterate on layout without writing code
- **Design tokens** — CSS custom properties for consistent colour and spacing
- **Visual hierarchy** — using size, weight, colour, and spacing to guide attention
- **Heuristic evaluation** — evaluating a product against Jakob Nielsen's 10 usability heuristics

### 💻 Development Skills Gained
- **Semantic HTML5** — proper use of `<section>`, `<nav>`, `<article>`, `<header>`, `<footer>`
- **CSS custom properties** — site-wide design system in `:root {}`
- **CSS Flexbox** — for single-axis layouts (navbar, button groups, stat rows)
- **CSS Grid** with `auto-fill` + `minmax` — responsive card grids without media queries
- **Mobile-first approach** — writing base styles for mobile, then adding `min-width` breakpoints
- **Vanilla JS DOM** — `querySelector`, `classList.toggle`, `addEventListener`, `getBoundingClientRect`
- **Scroll events** — used for navbar shadow, scroll reveal, active nav, back-to-top visibility
- **Git** — meaningful commits, `.gitignore`, remote push to GitHub

### 🌍 Professional Skills Gained
- Working to a **real deadline** in an office environment
- Receiving **mentor feedback** and revising design decisions based on it
- **Critically analysing** an existing product rather than building from scratch
- Writing **documentation** that explains why decisions were made, not just what
