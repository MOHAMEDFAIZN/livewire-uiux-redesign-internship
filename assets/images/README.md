## 📌 How to Add Images

1. Download or export your images from Figma / screenshot tools
2. Compress them using [squoosh.app](https://squoosh.app) or [TinyPNG](https://tinypng.com)
3. Place in this folder with the exact filenames listed above
4. Reference them in `index.html` or `style.css` as `assets/images/<filename>`
