# 📁 assets/icons — Icon Assets

This folder holds any custom SVG icons or favicons used in the project.
Font Awesome 6 (CDN) handles most icons — this folder is for custom/brand SVGs only.

## Files Expected Here

| File | Purpose |
|---|---|
| `favicon.ico` | Browser tab icon |
| `favicon-32.png` | 32×32 favicon for modern browsers |
| `apple-touch-icon.png` | 180×180 icon for iOS home screen |
| `icon-star.svg` | Custom star rating icon |
| `icon-placement.svg` | Custom placement badge icon |

## Tools Used
- [Figma](https://figma.com) — for creating custom SVG icons
- [RealFaviconGenerator](https://realfavicongenerator.net) — for favicon set generation
- [Font Awesome 6](https://fontawesome.com) — loaded via CDN in `index.html`
