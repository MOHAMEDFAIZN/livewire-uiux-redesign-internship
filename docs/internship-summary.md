## 4. Project Description

The project assigned during this internship was titled **"Developing Responsive Frontend Websites"**, with a specific focus on redesigning the Livewire India company website (`livewireindia.com`).

The original website, while functional, had several UI/UX weaknesses:
- Not fully mobile-responsive
- Navigation was dense and unclear on small screens
- Hero section lacked a clear single call-to-action
- Course cards showed limited information
- No visual feedback on interaction (hover states, animations)

My task was to:
1. Study the existing site and document its weaknesses
2. Create wireframes for an improved layout
3. Build a static HTML/CSS/JS prototype of the redesigned homepage

## 5. Week-by-Week Activity

### Week 1 — Research, UI/UX Concepts & Wireframing (01–06 Jul)

**Day 1 (01 Jul):** Orientation, introduction to Livewire, exploring the existing website. Set up VS Code and Git environment.

**Day 2 (02 Jul):** Introduction to UI/UX design principles. Learnt about the 4-step UX process: Research → Wireframe → Prototype → Test. Studied visual hierarchy and whitespace.
